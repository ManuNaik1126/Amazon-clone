# 🛒 Amazon Clone

A front-end clone of Amazon's website built using **HTML and CSS**. This project recreates the basic layout and visual design of an e-commerce website for learning and practicing web development.

## 🌐 Live Demo

🔗 **Live Website:** [Amazon-clone](https://manunaik1126.github.io/Amazon-clone/)

## ✨ Features

- Amazon-inspired homepage design
- Navigation bar with logo, search bar, and account section
- Product categories and promotional banners
- Product cards and shopping sections
- Footer with useful links
- Responsive styling, if implemented

## 🛠️ Technologies Used

- **HTML** – Structure of the webpage
- **CSS** – Styling, layout, and visual design

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code.
